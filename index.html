Five-condition experiment

Three one-minute practice blocks, followed by five counterbalanced three-minute test blocks. Keep this tab visible; use headphones for the audio task.

Experiment setup

Response mapping: S = same; D = different (mental rotation or phonemes). Tetris: ←/→ move, ↑ rotate counterclockwise, ↓ soft drop, Space hard drop to ghost. Both tasks run simultaneously in dual-task blocks. Mental rotation uses image files from stimuli/rotations/ and stimuli/mirrored/; phonemes use stimuli/step1.wav through step7.wav.

Practice before test: Tetris solo 1:00, phoneme discrimination 1:00 with easy same and far-apart sounds, and mental rotation 1:00 with easy figure pairs. Practice is recorded in the CSV. The five test conditions each last 3:00: Tetris solo, phonemes solo, mental rotation solo, mental rotation + Tetris, and phonemes + Tetris.

Leave sequence blank for automatic rotating allocation on this browser (ten balanced sequences); enter 1–10 to coordinate assignments across devices. Automatic allocation cannot coordinate across different browsers or devices. Re-entering the same participant ID on this browser reuses their sequence.
